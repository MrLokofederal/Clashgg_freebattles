# Clashgg_freebattles

Price / day is 1.25$.

You can book any day if spots are not full.

For more information:
  - Discord: https://discord.gg/QPmV9jdBAB

How to start:

  - Download the .exe file.
  - Run the .exe file and input your refresh_token when asked, you can find this by going to Clash.gg -> F12 -> Application -> Local Storage -> "refresh_token"
  - This will generate an exclusive solana wallet for your payments, then you will be able to book any day from the calendar if spots are not full.
  - After trying to book any day you will be prompted to make the payment of 1.25$ x days you trying to book.
  - After the payment, you can run the bot in the "Run bot" option when your day comes, you will have to let your PC online, we can run it for you with an extra +0.75$ / day.
